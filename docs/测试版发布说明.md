# 无间道 0.1.0-beta.2 · 公开测试版

> 「Dario，我係中國人。」🕶️

为国人使用海外 AI 保驾护航。帮助检查网络环境、排查配置隐患；不保证 Claude 等服务的账号状态。

## 本版更新

- 系统 DNS 支持手动输入和 Cloudflare / Google 预设，保存后回读确认，界面区分网卡保存值与当前生效入口。
- 改进 Clash Verge Rev / Mihomo 全局 TUN 保护兼容性，保留节点端点、DNS 接管及防火墙核验。
- 系统国家/地区可跟随已确认的出口，保留界面语言，并支持恢复。
- 修复 macOS 管理组件更新、临时签名和启动验证。
- 完善本机脱敏诊断日志，方便排查和反馈。

## 下载

在本页 Assets 中选择安装包：

- Mac Apple Silicon：`aarch64-apple-darwin.dmg`，需要 macOS 14+。
- Mac Intel：`x86_64-apple-darwin.dmg`，需要 macOS 14+。
- Windows x64：`x86_64-pc-windows-msvc-setup.exe`。
- Linux x64：`x86_64-unknown-linux-gnu.deb` 或 `.AppImage`。

每个安装包均附 `.sha256` 校验文件，各目标附 `build-*.json` 版本与源码提交记录。macOS 使用 ad-hoc 临时签名，未经 Apple 公证；Windows 未做代码签名。

## 使用前了解

当前仍为测试版，Windows / Linux 尚需更多实机验证。全局保护要求 Clash Verge Rev / Mihomo 开启 Global + TUN 并接管 DNS 53 端口。保护作用于整机，可能影响其他应用；退出 App 不会自动解除规则。请先了解停止保护和紧急恢复方法。

Windows 对指定节点端点上其他 IP 协议的限制与 macOS / Linux 不完全一致；Linux DNS 设置可能被网络管理器或重启覆盖。CI 通过不能代替实机上的断线与恢复验收。
