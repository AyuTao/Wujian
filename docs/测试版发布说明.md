# 无间道 0.1.0-beta.2 · 内部测试草稿

本版更新系统 DNS 设置、全局 TUN 保护兼容性、系统国家/地区跟随及诊断日志。安装包只上传未发布的草稿 Release，不公开发布。

- DNS 手动输入、Cloudflare / Google 预设及“改海外”统一为显式保存：写入并回读全部成功后，停止保护保留新值；失败或回执中断仍保留恢复状态。界面分开显示网卡保存值与系统生效解析入口，设置页展示每块网卡和读取时间，日志分别记录两者分类。
- 三端全局保护将未确认的代理 DNS 配置作为提示，保留 Global、TUN、DNS 53 接管、节点端点与防火墙核验。配置里有 114 等国内 DNS 不单独阻止开启，也不代表解析已在海外或已经证明无泄露。未知 DNS 不增加物理出口例外。
- 当前用户地区为中国大陆、香港或澳门时，可跟随已确认的 IP 出口国家/地区，保留界面语言；出口地区未知时建议手动修改。首次变更前备份，支持恢复并暂停自动地区跟随。
- macOS 管理组件增加版本核对、独立临时签名、launchd 安装及启动验证，处理残留网络服务和不存在的网卡。旧组件仅在用户明确操作时请求一次授权更新；失败保留恢复记录。
- 补齐 DNS 分阶段诊断、字段检查分类和恢复日志。导出不包含代理配置、原始错误、IP、凭据、网卡名称或用户路径。

## 三端范围

| 平台    | DNS 设置                                                         | 地区跟随                                                                                 |
| ------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| macOS   | 现有物理网络服务，含断网/停用服务；保存静态值                    | 当前用户 AppleLocale，保留 AppleLanguages                                                |
| Windows | 现有物理网卡 IPv4 DNS，含断网/停用网卡                           | 当前用户国家/地区及区域格式，保留显示语言                                                |
| Linux   | 活动接口的 systemd-resolved 运行时 DNS，网络管理器或重启可能覆盖 | GNOME / KDE 格式设置或 systemd 用户格式配置；需要已安装目标 UTF-8 locale，可能需重新登录 |

代理客户端也可能在启动/退出时覆盖系统 DNS；本工具不改写第三方备份或持续抢写。建议停止保护、完全退出客户端后修改，再重新启动客户端。DNS 配置不等于实际解析位置。

## 验证与反馈

本机 macOS 已通过 151 项 Rust 测试、33 项前端测试、类型检查及生产构建。对应提交的三端 CI 与打包结果见 GitHub Actions；CI 不能代替测试设备上的管理员授权、地区变更、真实断线/恢复及浏览器 DNS/WebRTC 验收。

Windows/Linux 的本轮设置变更尚需实机测试。Windows 防火墙对指定节点端点上其他 IP 协议的限制与 macOS/Linux 不完全一致；Linux DNS 不承诺跨重启持久保存。

macOS 安装包使用 ad-hoc 临时签名，未经 Apple 公证；Windows 安装包未做代码签名。每个安装包附 SHA-256 和对应目标平台的构建提交记录。

请阅读 [测试指南](测试指南.md)，在可本地恢复的测试机或虚拟机上测试。反馈包含版本、系统/CPU、复现步骤、规则回读与实际断流/恢复结果，并附 App 导出的脱敏日志；不要上传订阅、代理配置、恢复记录或原始设置。
