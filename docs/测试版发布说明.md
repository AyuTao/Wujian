Wujian 0.1.0-beta.1 · 首个公开测试版本

新增三端只读网络检查、分别授权的出口/DNS 采样、管理员授权的 IPv6 阻断与整机隔离、可恢复的 DNS 修改，以及本机轮转诊断日志与脱敏导出。修正规则模式误报全局、HTTP DNS 假通过、正常重测误触隔离等问题。

请先阅读仓库 docs/测试指南.md，从只读检查开始，在可本地恢复的测试机进行断流测试。

这是轮询触发且依赖管理员授权的 beta，不保证瞬时断流、崩溃时自动拦截或账号不被封禁。规则回读不代表实际断流已经验收。地区数据库不随包分发，缺失时地区显示未知。

macOS 包使用 ad-hoc 签名，未经 Apple 公证；Windows 包未做代码签名。每个安装包附有 SHA-256 文件。

反馈请包含版本、系统/CPU、复现步骤、规则回读与实际断流结果、是否能恢复，并附应用导出的脱敏日志。不要上传代理配置、恢复记录或原始设置。
