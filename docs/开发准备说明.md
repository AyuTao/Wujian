## 2. 前端 Skill 与视觉方向

项目已引入 Anthropic 官方 [frontend-design](https://github.com/anthropics/skills/tree/41bbe19d1a1a7eaab5e7bb9050a417e5c6cffc8f/skills/frontend-design)，位于 [`.agents/skills/frontend-design/`](../.agents/skills/frontend-design/SKILL.md)。保留原始 Apache-2.0 许可证与版权声明；没有因此确定本项目源码许可证。

设计采用冷白浅色基准、蓝色主操作、紧凑工具行、详情抽屉和清楚的状态。首次主题跟随系统，提供浅色和暗色。动效由 CSS 与 Motion 完成，只强调检测进度、展开与操作反馈，并尊重减少动态效果设置。

浏览器预览使用演示数据并持续显示标识；桌面模式调用原生模块，不能把演示结果补入真实快照。

## 3. 工程与本轮边界

- Tauri 2 + Rust；React + TypeScript + Vite；CSS Modules、CSS 变量与 `motion/react`。
- 首批面向 Claude Code、Codex CLI 等明确适配对象。发现、启动、保护分别报告能力，不能互相推导。
- 本地只读扫描固定目录、PATH 和系统配置；不执行工具登录，不读取账户密钥，不扫描整盘。
- ipify 公网 IP 与 ip-api HTTP DNS 观测分别征得同意；无需第三方账号或 API Key，不静默换路或降级。
- HTTP DNS 结果标记 `http_unverified`，不作为可信放行证据；单次 IP 只代表所示探测路径。
- 启动使用固定工具适配器与结构化参数，不开放任意 Shell 命令输入。它不建立系统访问规则，必须通过原生保护核验后才可调用；当前被门禁拒绝，不能控制从其他入口启动的工具。
- macOS、Windows、Linux 为目标平台；编译、实际检测、终端启动和保护的验证状态分别记录。

当前不安装高权限辅助服务，不修改本机 DNS、代理、路由、防火墙或既有 AI 工具配置。后续保护技术验证独立授权、独立验收后才能进入可用能力列表。

## 4. 运行与检查入口

安装对应系统的 [Tauri 开发依赖](https://v2.tauri.app/start/prerequisites/)，再从根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm tauri dev
```

`pnpm dev` 用于浏览器演示；`pnpm build` 检查并构建前端；`pnpm test` 与 `pnpm typecheck` 运行前端检查。原生调试构建使用 `pnpm tauri build --debug --no-bundle`。Rust 的 fmt/check/test 及平台 CI 配置见 [README](../README.md)。

根目录锁文件随代码提交后，CI 使用冻结安装；不在 CI 中隐式更新依赖。系统开发库由各平台环境单独准备，本项目不替用户自动安装系统工具。

## 5. 本轮开发顺序

1. 建立工程、版本、命令权限及依赖锁文件，先检查本机构建链。
2. 完成工具首页、详情、记录和设置；覆盖未知、未运行、失败和不支持状态。
3. 接入 Rust 快照、工具发现、本地检查与固定启动适配器。
4. 接入分别授权的外部探测，验证超时、错误、路径和结果范围；测试优先使用可控夹具，不向真实 AI 服务发送业务请求。
5. 复核原生窗口、键盘、主题与减弱动效，记录本机与三平台 CI 结果。
6. 优先推进必备的系统级保护，先完成一个平台、一个具体工具的技术验证，再扩大范围。

本轮结束时按[开发进度](开发进度.md)登记每项通过、失败或未验证，不提前勾选。项目名称已确定为无间道；正式许可证、签名和公开发布在后续阶段处理。
