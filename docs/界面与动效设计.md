# 无间道：单页界面

更新：2026-10-21。此版替代此前的侧栏、多页和工具抽屉方案，依据用户最新确认：整个工具只要一个页面。

## 页面顺序

1. 无间道名称、检测设置入口。
2. 实际隔断状态与原因、启用隔断和检测网络按钮。
3. 公网出口 IP、出口地区、稳定性和本次检测路径。
4. DNS、WebRTC、公网 IPv6、时区建议，点击原位展开具体证据。
5. 工具选择、扫描、添加和启动；添加路径在本页展开。
6. 检测设置、本机证据和最近变化，均在本页折叠；报告从记录区域导出。

不设置侧栏、页面路由、独立设置页、独立记录页或工具详情抽屉。

## 展示规则

系统阻断当前未实现，因此显示“隔断尚未启用”，启用和受保护启动保持不可用，不能展示“允许访问”或“已隔断”的伪成功。

出口 IP 只使用 egress-ipv4 的当前有效结果，不从任意含有地址的检查项推断。出口地区、稳定性和 WebRTC 尚未实现，明确显示待确认或未检测；不以 DNS 服务器地区代替出口地区。电脑时区只读显示，出口时区未知时不提出修改建议。

DNS 详情分开解释解析服务器归属和客户端子网归属。未知、过期、HTTP 辅助信息和本机配置识别继续区分。只有待处理事项和必要说明展开，不填充安全评分。

## 视觉与交互

沿用系统字体与冷白/蓝色主题，支持现有暗色。移除重复的工具行状态和导航。状态与出口优先，检测内容采用紧凑的两列信息行，不使用巨大盾牌、地图、装饰性仪表盘或评分卡。

首次加载只作一次轻微淡入；展开由用户触发。遵循系统减少动态效果，按钮和原生折叠项保留键盘焦点。窄窗口改为单列。

## 数据与能力

沿用已保存的检测授权，不重置设置，不隐式授权新服务。默认不自动发起外部请求。浏览器模式持续显示模拟数据标识，原生错误不回退演示。

本次是界面收敛，未安装系统保护组件，也未更改系统 DNS、Tailscale、代理、防火墙或路由。后台阻断及三平台覆盖的实际状态以《开发进度》为准。
