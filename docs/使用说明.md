# 无间道 · 详细使用说明

**免费提供的本机网络环境检测与防火墙连接控制工具。** 面向使用 AI 工具的用户，帮助查看出口、DNS、IPv6、时区及网络接管状态，并在启用保护后，按已确认的策略限制网络连接，条件失效时执行隔断。

项目采用 Tauri、Rust 和 React，面向 macOS、Windows、Linux，当前版本为 **0.1.0-beta.2**。目前仍在测试阶段。

本项目不收取软件使用费，不提供代理内核、节点、订阅或流量服务。使用者需要自行准备已有的网络环境，并确认自己有权管理相关设备、配置与连接。

> **隔断范围：当前实现使用整机防火墙规则，不是按 AI 应用进程单独拦截。** 保护和隔断可能影响浏览器、下载及其他应用。界面检测结果也不能证明每个 AI 请求都采用了同一路径。

## 主要功能

| 功能           | 说明                                                                                                                        |
| -------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 环境检测       | 查看公网出口及地区、DNS 解析出口、系统 DNS、IPv6、时区、采样路由和可识别的代理模式。未知、失败、过期结果分别显示。          |
| 防火墙保护     | 核对已有网络配置后，安装本机限制规则；由常驻组件检查策略状态，失效时执行整机隔断。                                          |
| 独立 IPv6 阻断 | IPv6 行的“阻断 / 恢复”单独管理公网 IPv6 规则，不清除网卡 IPv6 地址，不启用整机保护；恢复时保留 DNS 和时区配置。             |
| DNS 设置       | 支持手动填写系统 DNS，以及 Cloudflare、Google 公共 DNS 预设；写入前检查可用性；两处入口成功后均保留新配置，停止保护不还原。 |
| 出口时区跟随   | 根据实际出口查询城市时区，核对网络状态后修改系统时区；首次修改前备份原值，查询失败保留当前时区。                            |
| 登录启动       | 可设置当前用户登录桌面后打开 App；“登录后自动开启保护”为另一个独立开关，默认关闭。                                          |
| 本机日志       | 记录检测、配置、隔断、恢复及前端异常，支持查看、复制、选择文件夹导出和打开日志位置。                                        |

设置按“启动与检测 / DNS / 日志”分类。当前窗口默认大小为 520×800，可调整大小。

## 检测与系统修改

环境检测用于帮助用户判断本机状态。两个目标的采样路由经过 TUN，不代表所有应用流量均已接管；规则模式也不会显示成全局模式。

- **外部查询：** HTTPS 出口查询和 HTTP DNS 辅助采样在新安装及旧版首次迁移时默认开启，可在设置分别关闭。检测服务会接收到请求相关的网络信息；本机检测并不意味着所有查询都在离线完成。
- **DNS 观测：** 出口行显示网站请求的观测地址，DNS 行显示本次解析器出口采样，两者不要求相同。HTTP 辅助采样未经可信传输保护，仅供参考，不作为自动隔断依据；浏览器的 DNS/WebRTC 需在浏览器中另行检查。
- **系统 DNS：** 检测涵盖可读取的系统解析入口及作用域，不覆盖全部客户端内部上游、应用自有 DoH 或全部域名。修改系统 DNS 不等于修改 Clash/Mihomo 的内部解析策略。
- **DNS 预设：** Cloudflare 使用 `1.1.1.1 / 1.0.0.1`，Google 使用 `8.8.8.8 / 8.8.4.4`。服务商与地址不能单独证明实际解析位置，仍需检测。主界面识别到部分国内公共 DNS 时，也提供切换入口；仅点击后执行修改。设置页手动输入、预设和主界面快捷入口行为一致：逐网卡备份、写入并回读，全部成功后提交为新的系统设置并清除本次回滚记录。停止保护或恢复本工具配置时保留已提交的新 DNS；需要改回原值时，请手动配置。失败、回读不匹配或回执中断时保留待恢复状态，不能报告成功。macOS / Windows 包含已安装但暂时断网、停用的物理网卡；已拔除设备、虚拟/TUN 网卡及将来新增网卡不在范围内。Linux 目前只支持活动接口的运行时配置，网络管理器或重启可能覆盖。
- **时区：** 当前启动流程会将保存的时区模式设为“跟随出口”。查询依次使用 `ipinfo.io`、`ipwho.is`，匹配具体出口与城市时区，不按国家猜测。实际修改通过管理员组件完成；首次需要系统授权。恢复原时区会停止本次跟随，但再次启动仍会按当前启动流程设置跟随模式。
- **客户端与 DNS 恢复：** 代理客户端可能保存并在退出时恢复旧系统 DNS；例如 Clash Verge Rev 的 macOS 退出流程包含此操作。建议停止保护、完全退出客户端后再应用 DNS，然后重新启动客户端。App 不改写第三方备份，也不持续抢写网卡设置。界面“DNS 配置”分两行显示物理网卡保存值与当前生效解析入口，后者可能含 TUN / VPN。设置页可查看每块网卡及最近读取时间；Linux 显示活动接口运行时值。两者随本地检测刷新，读取失败显示未知，不用生效入口冒充网卡静态值。该行标为“参考”，114 等地址不会单独阻止开启全局保护；这也不是无泄露证明。日志分别记录 `dns.physical` / `dns.effective` 的 `domestic / configured / automatic / empty / unavailable` 等分类，不导出地址或网卡名称；`configured` 仅表示已读取到配置。
- **权限：** 查看与修改分别处理。防火墙、DNS、时区修改需要相应系统权限；开机启动设置使用当前用户的系统登录启动项。请将 App 安装到稳定位置后再开启登录启动。

**Mac 更新说明：** App 与管理员组件分别安装。执行需要管理组件的操作前，App 会核对组件协议、版本及可用的构建标识；旧组件由用户手动操作触发一次管理员授权更新，更新后回读确认再执行本次操作。后台检测与自动开启保护不会自行弹授权。更新组件保留既有防火墙规则和 DNS 恢复记录；回执中断时不盲目重复已经提交的修改。 后台程序从 App 复制后会单独做临时签名和验证，安装文件设为 root 所有；安装会启用本组件、等待旧服务退出，并通过版本回执确认启动。失败时保留安装文件与恢复记录，App 日志记录失败阶段。

**系统国家/地区跟随：** 当前用户的系统地区为中国大陆（CN）、香港（HK）或澳门（MO）时，跟随已确认的 IP 出口国家/地区；只调整国家/地区和区域格式，保留系统界面语言。与时区复用 HTTPS 城市查询，核对返回 IP、查询前后的出口及网络配置；国家已知但城市时区未知时可独立调整地区。出口地区未知时保留原值，主界面提示建议手动修改，并提供系统地区设置入口，不默认选择其他国家。首次修改前保存原值，后续只继续跟随本工具仍持有的设置；外部手动修改会保留。设置中的“恢复原地区”会恢复本工具修改并暂停地区自动跟随。

| 平台    | 地区设置范围                                                                                                                                                                                     |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| macOS   | 当前用户 `AppleLocale` 中的地区，保留语言、脚本与其他区域选项，不改 `AppleLanguages`                                                                                                             |
| Windows | 当前用户国家/地区和区域格式，不改界面语言列表、显示语言或系统非 Unicode 程序语言                                                                                                                 |
| Linux   | GNOME 地区格式、KDE 的格式分类；其他 systemd 用户会话写入本工具的 `environment.d` 格式文件，保留 `LANG` 与 `LC_MESSAGES`。目标 UTF-8 locale 未安装或 `LC_ALL` 覆盖时提示手动设置，不猜测替代地区 |

地区设置保存后，已运行应用可能需重启；Linux 桌面可能需重新登录。读取、决策、修改、回读及恢复均记入脱敏诊断日志。Windows/Linux 适配尚需各平台实机复测，地区设置不代表 IP 地址或服务端识别结果发生变化。

出口地区通过本机 `Country.mmdb` 查询，不自动下载或分发数据库。普通出口显示可以使用设置指定的数据库；全局保护另从桌面用户目录中的已有数据库核对节点。未找到数据库或无法确定地区时显示未知，不填写默认国家。

## 防火墙如何工作

普通环境检测可用于多种已有网络环境。**当前全局保护适配 Clash Verge Rev/Mihomo，要求已有客户端开启 Global + TUN，并接管 DNS 的 53 端口。** 软件不提供这些客户端或其连接资源，也不自动切换客户端的 Global/TUN 模式。

当前保护策略还有以下限制，启用前应核对确认框：

- GLOBAL 必须最终选择单个受支持节点。准备计划时检查节点及必要 DNS 节点的公网 IPv4 和地区；当前策略拒绝中国大陆、未知或国家不一致的结果。这是本项目现有的策略限制，不是对某种联网方式的合法性认证。
- DNS 主上游、fallback 和域名策略作为诊断提示，不因未写 `#代理组`、未开启 `respect-rules` 或上游格式未识别而阻止开启。配置本身不能证明已发生泄漏。可识别的额外 DNS 代理节点仍须核对精确端点；未知解析器不会加入物理网卡放行列表。开启后若客户端尝试公网直连 DNS，可能被规则阻断而无法解析，请在客户端检查配置。
- 系统 DNS 修改与代理客户端 DNS 分开处理，App 不自动改写订阅或客户端配置。日志只记录 DNS 各字段的诊断分类，不包含原始配置、策略域名、代理组名或订阅。
- 保护只放行指定 TUN、计划中精确的节点端点、必要的 DNS 节点端点，以及限定的本地通信；不因为某个应用属于 AI 工具就单独获得放行权限。
- provider、插件、链式代理、负载均衡和端口跳跃等配置暂不适配。准备计划失败时，应查看具体原因。

确认并启用后，规则驻留于系统防火墙。常驻组件检查全局模式、指定 TUN、节点选择、已确认的额外 DNS 代理端点与控制接口；条件失效时尝试切断到仅保留本机回环通信。同一节点和 DNS 路径恢复后，会尝试按原计划继续保护；TUN 接口名称变化可以重新绑定。节点、端口或已确认的额外 DNS 代理端点变化时保持隔断，需要明确停止后重新确认。

**自动操作需要分别了解：**

- “开机自动启动”负责登录后打开 App；“登录后自动开启保护”默认关闭。打开后，App 启动会尝试启用保护；当前节点不合格时，会尝试同组已有的其他线路，成功后保留新选择，失败时尝试切回原选择并报告错误。
- 当前启用流程会先尝试跟随出口时区；如果系统时区仍被识别为中国大陆，会进入整机隔断流程。此路径可能直接改变联网状态；规则是否加载成功以回执与错误信息为准。
- 保护运行期间，网站出口 IP、地区和 HTTP DNS 观测通常作为诊断信息；这些观测变化不等同于节点配置变化，也不自动替换已确认的策略。

## 平台与测试状态

| 平台      | 防火墙及常驻组件                                                             | DNS 修改                                                   |
| --------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------- |
| macOS 14+ | PF 独立 anchor、launchd 常驻组件；首次需要管理员授权                         | 使用 networksetup，修改现有物理网络服务，含断网/停用服务   |
| Windows   | Windows Defender Firewall、SYSTEM 计划任务；操作可能请求 UAC                 | 修改现有物理网卡 IPv4 DNS，含断网/停用网卡                 |
| Linux     | nftables 独立表 `inet wujian_guard`、systemd；需要 nftables 与 polkit/pkexec | 目前支持 systemd-resolved/resolvectl，备份并恢复每接口 DNS |

**目前尚未完成全部真实断线、断流与恢复验收，Windows/Linux 尤其需要实机测试。** CI 编译和测试通过不代表每个设备、网络客户端及系统版本均可正常隔断。

macOS 和 Linux 在保护期间保留限定的局域网通信，进入完整隔断后仅保留回环。Windows 的物理网卡限制实现与两者不同：指定节点端点上的部分其他 IP 协议仍可能通过，不能据此承诺与 macOS/Linux 完全相同的隔离效果。

常驻组件约每 2 秒检查一次状态，检查与执行耗时会延长实际间隔；界面本地巡检约每 3 秒，外部观测通常每 15 秒、保护期间约每 10 秒更新。系统开机早期、其他管理员软件改写规则、组件故障等情况不在“零泄漏”保证内。`configurationActive` 表示规则配置回读匹配，不能代替实际数据包隔断验证。

请先阅读 [测试指南](测试指南.md)，从环境检测开始。断流用例应在能本地恢复的测试机或虚拟机执行。已有验证与待测项目见 [开发进度](开发进度.md)。

## 停止与恢复

1. 在界面选择停止保护或解除隔断，解除本工具加载的防火墙限制。
2. 需要同时恢复 DNS 与时区时，选择“恢复本工具配置”；它只恢复仍有备份记录的修改，不重置所有网卡。显式 DNS 修改成功后保留的新值不会由此自动还原。
3. 独立 IPv6 模式使用 IPv6 行的“恢复”，不会顺带还原 DNS 或时区。
4. 若启用了“登录后自动开启保护”，不希望下次启动再次启用时，先关闭该开关。

UI 退出或崩溃不会自动清除已加载的规则。若界面无法使用，可通过已安装常驻组件的 `--emergency-release` 入口恢复；macOS 的命令为：

```sh
sudo /var/db/io.wujian.firewall/tunnel-helper --emergency-release
```

常规恢复只卸载本工具的组件和规则：macOS 不关闭全局 PF；Linux 只删除本工具的 nftables 表；Windows 只删除本工具的防火墙组。请勿通过清空系统防火墙来代替恢复。Windows/Linux 的紧急恢复仍需实机验收。

## 日志与数据

结构化诊断日志保存在本机，不自动上传。日志记录操作 ID、结果、耗时、错误类别、版本、平台及构建标识，不记录原始错误、IP、凭据、命令参数或用户路径。界面显示的网络状态和业务历史与这份诊断日志的字段范围不同。

App 与管理员组件分别保留四份约 512 KiB 的轮转日志。导出时合并可收集的记录，标明完整性及日志健康状态；Windows/Linux 收集系统保护日志可能需要管理员授权。用户可自行选择导出位置，向他人提供前应检查导出内容。

本工具帮助检查环境与控制连接，不提供 AI 服务，也不保证第三方账号状态或服务可用性。请在有权管理的设备和依法接入的网络中使用，并遵守所用服务的规则。

## 开发与检查

需要 Node.js 22、package.json 指定的 pnpm、Rust stable，以及对应平台的 Tauri 编译依赖。Linux 构建依赖见 [check.yml](../.github/workflows/check.yml)。

```sh
pnpm install --frozen-lockfile
pnpm tauri dev
```

```sh
pnpm test
pnpm build
pnpm format:check
cargo fmt --manifest-path src-tauri/Cargo.toml --all -- --check
cargo test --manifest-path src-tauri/Cargo.toml --locked
```

`pnpm tauri build` 构建当前平台。GitHub Actions 提供三端检查；手动测试打包流程生成未发布草稿，安装包仅上传该草稿，附 SHA-256 校验与构建提交，不自动公开发布；[0.1.0-beta.2](https://github.com/AyuTao/Wujian/releases/tag/v0.1.0-beta.2) 已由维护者公开发布为测试版。macOS 测试包使用本地临时签名（ad-hoc），不使用 Apple 开发者证书，也未做 Apple 公证；Windows 测试包未做代码签名。

`native/macos/` 的 Network Extension 是独立研究组件，当前桌面包不安装或启用它。代码保留的应用发现与普通快捷启动接口不代表已对每个 AI 应用实现独立进程级防火墙。`docs/` 中其他方案文档保留为设计资料，当前行为以本 README、对应代码和测试结果为准。
